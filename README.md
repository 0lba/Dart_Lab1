# Dart_Lab1 #
Консольное приложение на языке Dart для анализа успеваемости студентов. Программа принимает список оценок и выводит статистику: средний балл, максимум, минимум и итоговую оценку.

__Как запустить__
1) Клонировать репозиторий:
'''
git clone https://github.com/0lba/Dart_Lab1
'''
2) перейдите в папку проекта:
'''
cd lab1.dart
'''
3) Установить зависимости:
'''
dart pub get
'''
4) Запустить приложение:
'''
dart run
'''

__Ответы на вопросы:__
1) В Python динамическая, типизация тип переменной определяется автоматически. в Dart статическая типизация, тип переменной известен на этапе компиляции и не может быть изменён после присвоения.
Практическое преимущество:
Компилятор ловит целый класс ошибок ещё до запуска программы. Например, попытку присвоить строку в переменную типа int.
2) String? - это тип, который может содержать либо строку, либо null. String - это тип, который гарантированно не может быть null.
3) Это защищает от случайного изменения важных значений и делает намерения программиста явными для других разработчиков.
4) Позиционный параметр передаётся по порядку, без указания имени:
'''
String greet(String name) => 'Привет, $name!';
greet('Артём');
'''
Именованный параметр передаётся с указанием имени и заключается в фигурные скобки. Если стоит required, его обязательно нужно передать:
'''
void describePet({required String name, String species = 'кот', int age = 0}) {
  print('$name - $species, возраст $age');
}
describePet(name: 'Барсик', age: 3);
describePet(name: 'Шарик', species: 'пёс');
'''
