# Dart_Lab1 #
## Консольное приложение на языке Dart для анализа успеваемости студентов. ##
## Программа принимает список оценок и выводит статистику: средний балл, максимум, минимум и итоговую оценку. ##

__Как запустить__
1) Клонировать репозиторий:
'''
git clone https://github.com/0lba/Dart_Lab1
'''
2) перейдите в папку проекта:
'''
cd lab1.dart
'''
3) Установить зависимости:
'''
dart pub get
'''
4) Запустить приложение:
'''
dart run
'''
